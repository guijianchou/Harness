# Noto Sans SC

`NotoSansSC.ttf` is the unmodified Noto Sans SC variable font from Google Fonts,
renamed from `NotoSansSC[wght].ttf` for a stable application asset path. No glyphs
or font metadata were modified.

- Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>
- Font download: <https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf>
- License download: <https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt>
- Retrieved: 2026-11-25
- Font version: `2.004-H2;hotconv 1.0.118;makeotfexe 2.5.65603`
- SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`
- Size: 17,772,300 bytes
- Typographic family: `Noto Sans SC`
- Variable weight range: 100–900; use weight 400 for regular text.

The font supports Latin and Simplified Chinese. Its Unicode character map was
checked for English letters, digits, and Simplified Chinese UI text.
