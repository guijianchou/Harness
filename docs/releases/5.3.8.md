Harness 5.3.8 brings optional OpenClaw Gateway controls, refreshed UI and branding, and lower chat-page inspection overhead.

## 更新内容 / Changes

- OpenClaw Gateway v4：原生会话列表、搜索与切换、模型选择、任务状态和精确停止；聊天输入、附件和内容渲染继续使用网页。此功能需在设置中主动启用。
- 优化顶栏、会话侧栏、首次使用引导和设置保存反馈；替换全套品牌图片与多尺寸程序图标。
- 限制页面状态检查的文本扫描量，找到可信模型控件后提前返回，并合并高频 DOM 变更检查，降低长会话中输入、滚动和折叠时的额外开销。
- 已连接的任务不会仅因输出暂时安静而自动同步或重载页面。
- Optional native Gateway v4 session/model/run controls, with protected credentials and persistent signed device identity.
- Refreshed toolbar, session workspace, Settings feedback, and application artwork.
- Bounded chat DOM inspection and coalesced mutation checks; quiet connected runs no longer trigger automatic page reloads.

## 安装与测试 / Run and test

1. 下载 `Harness-5.3.8-win-x64.zip`，完整解压到一个新目录。
2. 完全退出旧版 Harness（包括托盘中的实例），然后运行新目录中的 `Harness.exe`。
3. 原有配置和网页登录资料保留在 `%LOCALAPPDATA%\Harness`；无需删除该目录。
4. 优先测试长会话中的输入、滚动、折叠，以及程序文件、任务栏和托盘图标。启用原生 Gateway 后，再测试会话切换、模型应用、停止任务和断线重连。

Extract the whole ZIP, close the previous instance, and run `Harness.exe`. Settings and browser profiles stay in `%LOCALAPPDATA%\Harness`.

当前构建目标为 **Windows 11 24H2（26100）及以上，x64**。便携包自带 .NET 和 Windows App SDK，仍需要系统安装 **Microsoft Edge WebView2 Runtime**。旧版 Windows 兼容性未验证。

The ZIP includes .NET and Windows App SDK. It still requires the system WebView2 Runtime and targets Windows 11 24H2/build 26100 or later.

原生 Gateway 连接不自动继承网页的登录状态；直连和 Cloudflare 路径建议分别配置环境。配对或 Cloudflare Access 可能需要独立配置。详见 [OpenClaw 集成说明](https://github.com/Guijianchou/Harness/blob/5.3.8/docs/openclaw-integration.md)。

## 验证范围 / Validation scope

本地 Core 回归测试、桥接脚本、会话选择和原生 WebView2 验证已通过。1,000 条消息的合成 WebView2 场景中，单次页面状态检查 P50 从 628.6 ms 降至 4.5 ms，P95 从 855.5 ms 降至 6.3 ms；这些是合成状态检查耗时，不代表真实网页输入延迟或帧率。真实 VPS、直连和 Cloudflare 链路的端到端表现仍需实机反馈。

Local regression checks passed. The synthetic WebView2 benchmark measures inspection overhead, not live-site input latency or frame rate. Real OpenClaw VPS and Cloudflare end-to-end behavior still needs hardware testing.
