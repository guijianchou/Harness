Harness 5.3.11 protects OpenClaw session settings and subscriptions, improves update feedback, and keeps the app accessible when tray registration fails.

Release date: 2026-11-25.

## What's changed

- Preserve OpenClaw model and thinking overrides when the current model is unavailable or no settings were changed. Unavailable models appear as read-only information; Apply requires valid pending edits. Explicitly choosing Default still clears the override.
- Fix session subscription races when the webpage changes during a Gateway request. Subscription ownership follows the connection, late acknowledgements reconcile the active session, and uncertain subscription timeouts or cancellation rebuild the connection.
- Present checking, downloading, verification, and restart feedback in one responsive About card. Use inline retry/cancel actions, a small progress ring for non-download work, and a download bar only while downloading. Nonportable and Debug builds can check and open the release page.
- Respect GitHub rate-limit retry deadlines and show the local retry time. Distinguish access denial from rate limiting, merge concurrent checks, and reuse successful results, including no-update results, for five minutes while Harness is running.
- Confirm tray registration before hiding the main window. If registration fails, keep or reopen the window and show a warning so the app remains accessible.
- Report browser-profile directory access denial explicitly and include diagnostics for manual retry and recovery. Low integrity workspace outputs need deployment to a normal user directory; the app does not change Windows permissions or integrity labels.
- Expand session, update, tray, and WebView regression coverage, including the actual update ViewModel in CI and Release workflows. A remote Gateway or reverse-proxy failure still requires deployment troubleshooting; real Gateway and Cloudflare authentication/streaming validation remains separate.

## Installation

Official portable builds from 5.3.9 onward can check for this release in **Settings > About** and install it with **Save settings and restart to update**. Version 5.3.9 was the first release containing the updater; earlier packages require a manual upgrade.

For manual installation, download `Harness-5.3.11-win-x64.zip`, extract the entire archive into a new folder, close the old Harness instance, and run `Harness.exe`. For locally built outputs that inherit a Windows Low integrity label, ZIP the entire output and extract it into a normal user directory outside the workspace before running it.

Windows 11 24H2 (build 26100) or later is targeted. .NET and Windows App SDK are included; Microsoft Edge WebView2 Runtime is still required. See [portable update and recovery details](https://github.com/guijianchou/Harness/blob/5.3.11/docs/portable-updates.md).

## 简体中文

发布日期：2026-11-25。

- 当前模型不可用或设置未修改时，保留 OpenClaw 模型与推理强度覆盖。不可用模型以只读信息展示，“应用”仅在存在有效未提交修改时启用；主动选择“默认”仍会清除覆盖。
- 修复 Gateway 请求期间页面切换导致的会话订阅竞态。订阅归属跟随连接，迟到回执重新核对当前会话；订阅超时或取消、服务器状态无法确认时重建连接。
- 关于页用同一张自适应卡片展示检查、下载、校验与重启状态，支持行内重试/取消；非下载阶段使用小型进度环，仅下载时显示进度条。非便携版和 Debug 可检查并打开发布页。
- 遵守 GitHub 限流重试截止时间并显示本地重试时间，区分访问拒绝与限流，合并并发检查，并在应用运行期间缓存五分钟内的成功结果，包括没有更新的结果。
- 隐藏主窗口前确认托盘注册成功；失败时保留或重新打开窗口并提示，避免程序无法找回。
- 浏览器配置目录访问被拒绝时显示明确错误并提供诊断，支持手动重试与恢复。继承 Low 完整性标签的工作区产物需部署到普通用户目录；应用不会修改 Windows 权限或完整性标签。
- 扩展会话、更新、托盘和 WebView 回归，将实际更新 ViewModel 的展示回归接入 CI 与 Release。远端 Gateway 或反向代理故障仍需排查部署；真实 Gateway、Cloudflare 认证及流式输出仍需单独验证。

5.3.9 及之后的官方便携包可在“设置 > 关于”检查本次更新，并选择“保存设置并重启更新”。5.3.9 是首个包含更新器的版本，更早的包需手动升级。

手动安装时请完整解压 `Harness-5.3.11-win-x64.zip` 到新目录，退出旧版后运行 `Harness.exe`。若本机构建产物继承 Windows Low 完整性标签，请将整个输出目录打成 ZIP，再解压到工作区外的普通用户目录运行。

面向 Windows 11 24H2（26100）及以上，包含 .NET 和 Windows App SDK，仍需系统 WebView2 Runtime。详见[便携更新与恢复说明](https://github.com/guijianchou/Harness/blob/5.3.11/docs/portable-updates.md)。
