Harness 5.3.10 refines Settings with Mica, consistent cards, clearer feedback, and a simpler About page.

Release date: 2026-11-23.

## What's changed

- Use Mica across the Settings window, with a transparent custom title bar, sidebar, and footer. All seven pages share consistent headings, spacing, and card surfaces.
- Adapt navigation, editors, environment actions, and save/cancel controls to narrower windows. Saving settings and clearing browser data show progress feedback.
- Present Developer Tools as descriptive action cards with native hover and click behavior.
- Group the app icon, name, and version in About; simplify update guidance and make the project and release cards clickable. Omit the initial prompt to check for updates while retaining progress, results, and recovery messages.
- Fix Settings initialization by replacing the unsupported accessibility event subscription with the system color-change event supported by the unpackaged app. Theme changes and high-contrast fallback remain supported.

## Installation

Official portable builds from 5.3.9 onward can check for this release in **Settings > About** and install it with **Save settings and restart to update**. Version 5.3.9 was the first release containing the updater; earlier packages require a manual upgrade.

For manual installation, download `Harness-5.3.10-win-x64.zip`, extract the entire archive into a new folder, close the old Harness instance, and run `Harness.exe`.

Windows 11 24H2 (build 26100) or later is targeted. .NET and Windows App SDK are included; Microsoft Edge WebView2 Runtime is still required. See [portable update and recovery details](https://github.com/guijianchou/Harness/blob/5.3.10/docs/portable-updates.md).
