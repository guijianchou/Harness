Harness 5.3.9 adds updates inside the portable app and includes the recent startup and UI reliability fixes.

## What's changed

- In **Settings > About**, check the latest stable GitHub release, download with progress and cancellation, and verify the ZIP checksum and every package file.
- Choose **Save settings and restart to update** to install in the same directory. Settings must save successfully before the app exits. The old program directory is retained as a backup; failed startup restores and restarts the old version.
- Keep configuration and browser profiles in `%LOCALAPPDATA%\Harness`, and preserve user-added files in the portable directory. Other running instances of that installation block replacement.
- Fix local build startup dependencies, improve Settings save/conflict feedback and narrow-window layouts, and improve Gateway state and hosted profile isolation.
- Include the self-contained updater and package manifest. CI verifies update success, startup-failure rollback, and an installation still used by another process.

## Installation

Download `Harness-5.3.9-win-x64.zip`, extract the entire archive into a new folder, close the old Harness instance, and run `Harness.exe`. Previously published 5.3.8 packages do not contain the updater and require this one manual upgrade. Future portable updates can be installed from About.

Windows 11 24H2 (build 26100) or later is targeted. .NET and Windows App SDK are included; Microsoft Edge WebView2 Runtime is still required.

After an update, the sibling `.harness-update-<id>\backup` folder retains the old installation. Keep it until the new version is confirmed working. See [portable update and recovery details](https://github.com/guijianchou/Harness/blob/5.3.9/docs/portable-updates.md).

## 简体中文

- 新增“设置 > 关于 > 检查更新”，支持下载进度、取消、SHA-256 和逐文件完整性校验。
- 点击“保存设置并重启更新”后，在原目录替换程序；设置保存失败则不退出。更新保留旧版备份，新版启动失败自动恢复并重启旧版。
- 保留 AppData 配置、浏览器资料和程序目录中的用户额外文件；同一安装目录有其他实例运行时不替换。
- 修复本机构建启动依赖，完善设置保存与冲突反馈、窄窗布局、Gateway 状态和托管配置隔离。
- 之前发布的 5.3.8 没有更新器，需先完整解压本次 ZIP 到新目录，退出旧版后运行 `Harness.exe`，完成一次手动升级。之后可使用应用内更新。

面向 Windows 11 24H2（26100）及以上，包含 .NET 和 Windows App SDK，仍需系统 WebView2 Runtime。更新后请先保留相邻 `.harness-update-<id>\backup`，确认新版正常后再自行清理。
